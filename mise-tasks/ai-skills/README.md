# AI Skills Tasks

Install and update agent skills in a project using the GitHub CLI.

**Prerequisites:** [GitHub CLI](https://cli.github.com/) (`gh`) with the `gh skill` command available.

| Name               | Description                    | Alias               |
| ------------------ | ------------------------------ | ------------------- |
| `skill:install`    | Install new skill using GH CLI | `skills:install`    |
| `skill:update`     | Update all skills              | `skills:update`     |
| `skill:update:all` | Update all skills              | `skills:update:all` |
