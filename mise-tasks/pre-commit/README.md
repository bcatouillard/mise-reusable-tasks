# Pre-commit Tasks

Install the project's pre-commit hooks and run configured hooks across all files.

## Prerequisites

- [pre-commit](https://pre-commit.com/)

## Tasks

| Name                | Description               | Alias                |
| ------------------- | ------------------------- | -------------------- |
| `precommit-install` | Install pre-commits hooks | `pre-commit:install` |
| `precommit-run`     | Run pre-commits           | `pre-commit:run`     |
